## 📌 Project Overview

**CodeAlpha Calculator** is a fully functional calculator web application created as part of the **CodeAlpha one-month Front-End internship**. It performs basic arithmetic operations (addition, subtraction, multiplication, and division) with a clean, user-friendly interface.

---

## ✨ Key Features

- ➕➖✖️➗ **Basic Arithmetic Operations** – Add, subtract, multiply, and divide
- 🖱️ **Interactive Buttons** – Click-based input with instant results
- 🎨 **Clean UI** – Simple, intuitive layout styled with CSS
- ⚡ **Lightweight** – Pure HTML/CSS/JavaScript, no external dependencies

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Calculator structure |
| **CSS3** | Styling and layout |
| **JavaScript** | Calculation logic and interactivity |

